# Overlay runtime cases

This folder holds the production-shaped overlay and portal runtime suite.

The cases are intentionally split from the other generated runtime fixtures so overlay behavior is easy to find and extend.

Coverage includes:

- `overlay_entry` / `overlay` trigger bindings and fixed placement
- `window` drag / resize / bounds checks
- `dialog` barrier and motion variations
- `sheet` and `drawer` spatial variants
- `popover`, `menu`, `dropdown`, `flyout`, `context_menu`, and `context_panel` trigger flows
- `anchored_floating` target-anchored overlays
- `persistent_panel` and `inline_expandable` inline surfaces
- `toast` auto-mount behavior
- `fullscreen_surface` barrier and safe-area variants
