
# SDUI Test Cases

Drop JSON test files into this folder.

The power test engine will scan them automatically.

## Rules

- Each file should be a valid JSON object.
- The JSON can be a normal SDUI document.
- You can add optional metadata under `__meta`, `__test`, `__expect`, `__viewport`, `__env`, or `__tags`.
- Nested folders are allowed.

## Example files

- `sample_home.json` — a basic passing screen example
